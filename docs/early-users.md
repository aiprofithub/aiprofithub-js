# Early Users

AIProfitHub JavaScript SDK is looking for early users building AI products in production.

The SDK is free. The commercial path is simple: install tracking, send useful AI usage events, then use AIProfitHub Cloud or an AI Spend Audit to find cost leaks, budget risk, and optimization opportunities.

## Best fit

- SaaS teams using OpenAI, Anthropic, Google, Groq, Mistral, LangChain, or custom LLM workflows
- AI chatbot agencies that need cost per client or cost per workspace
- teams shipping LLM features into production
- founders who want to understand AI API margin before usage scales
- engineering teams that need provider, model, feature, user, and customer attribution

## What to try first

1. Install the SDK.
2. Send one usage event with provider, model, inputTokens, and outputTokens.
3. Add customerId and feature as soon as possible.
4. Review the examples in this repository.
5. Open an issue with your use case if a tracking field is missing.

## What we want to learn

- Which AI cost fields teams already track
- Which providers and frameworks need better examples
- Which reports help founders, engineering, product, and finance teams
- Which cost leaks are painful enough to justify a paid audit
- Which workflows need optimizer, alerts, or routing recommendations

## Early-user offer

If you are using AI APIs in production, AIProfitHub can help you run a lightweight AI Spend Audit.

Useful inputs:

- provider and model list
- approximate monthly AI spend
- high-cost features
- customer or workspace count
- whether the AI feature is free, metered, or included in a paid plan

## Conversion path

```text
GitHub SDK
→ developer tries usage tracking
→ issue, discussion, star, or DM
→ AI Spend Audit
→ onboarding
→ usage upload or telemetry connection
→ report
→ dashboard, alerts, optimizer, and agents
```
