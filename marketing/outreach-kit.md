## Dev.to article

```markdown
# I built a free JavaScript SDK to track AI API cost before it becomes a margin problem

AI apps are easy to launch now.

But after launch, one thing gets messy fast: AI API cost.

Most teams know they are spending money on OpenAI, Anthropic, Google, Groq, or other providers. But they often do not know:

- which feature caused the spend
- which user burned the most tokens
- which customer is unprofitable
- which model should be downgraded
- when fallback routing silently increases cost

That is why I built the AIProfitHub JavaScript SDK.

It is a lightweight SDK for sending AI usage events into AIProfitHub, so teams can start building cost intelligence from day one.

## Who it is for

- AI SaaS founders
- developers building LLM-powered features
- product teams using multiple AI providers
- chatbot agencies
- teams that want usage attribution before cost gets out of control

## What to track

At minimum:

- provider
- model
- inputTokens
- outputTokens

Recommended:

- customerId
- userId
- feature
- route
- plan
- fallbackReason
- costUsd

## Repository

https://github.com/aiprofithub/aiprofithub-js

The SDK is free to try. Feedback is welcome.

I am also looking for early users who want help auditing their AI spend and finding cost leaks.
```
